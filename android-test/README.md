# ORIGIN — Android V10 test build

This folder is a **separate Android debug packaging project**. It does not modify any web page or design. It wraps the already-live V10 Cloudflare build at:

https://origin-creator-journey.rayadinaveen98.workers.dev/v10/

## How it works
- Android package: `com.origin.creatorjourney`.
- Debug version: `1.0.0-test` (`versionCode 10`).
- Requires Android 8.0+ and an active internet connection. The app renders the verified complete eight-act web journey, not bundled offline content.
- JavaScript and DOM storage are on to preserve the actual welcome animation, navigation, My List and life progress.
- Sources and archival links open in the external browser; all ORIGIN routes stay in the Android app.
- Android Back navigates WebView history when available.
- Dark native status/nav bars, HTTPS-only internal routing, no cleartext, no file access, no third-party cookies configured.
- An offline/network error page offers Retry.

## Build
GitHub Actions > **ORIGIN V10 Android Test APK** > current green run > Artifacts > `ORIGIN-V10-Android-Test-APK`.

The workflow uses JDK 17, Gradle 8.9 and Android Gradle Plugin 8.7.3. It builds `:app:assembleDebug`, validates package identity and uploads the signed debug APK.

For local builds, install Android SDK 35 / Build Tools 35.0.0 and Java 17:

```sh
gradle --project-dir android-test :app:assembleDebug
```

APK: `android-test/app/build/outputs/apk/debug/app-debug.apk`.

## Test limitations
This is a **web-powered Android test APK**, not yet the final native/offline ORIGIN app. Since the UI is served live, future website updates will also appear inside this APK. It does not contain copyrighted films, archival assets or audio offline.

This is signed with a temporary Android debug key generated by the build runner, **not** a stable release signing key. Uninstall a previous test APK with the same package name if Android reports an incompatible signing certificate. Do not distribute this build through app stores. A future production build needs stable signing, offline decisions, release QA and app policy review.

## Visual feedback checklist
Test first-load welcome, home, search, My List, portrait image availability, journey entry, 1921 life reader, later-year timeline, scrolling, Android Back/Home, rotate, slow internet and returning to Continue Journey. Record where story immersion breaks on the device.

### V10 journey scope

This review build launches the 8-act / 87-scene Satyajit Ray experience. It requires internet access and is intended for Android-device feedback, not commercial release. Existing Android debug installations may require uninstalling first because ephemeral runner signing keys differ.
